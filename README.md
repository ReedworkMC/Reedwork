## Documentation

📚 **Read the official Reedwork documentation:**

**[https://reedworkmc.github.io/reedwork/](https://reedworkmc.github.io/reedwork/)**

The documentation covers:

- Getting started and installation
- Annotation-based commands
- Brigadier integration
- Dependency injection
- Automatic event registration
- Custom enchantments
- Developer utilities
- Tutorials and examples

For detailed guides, API usage, examples, and tutorials, please refer to the official documentation.
